# Natural Language SQL Querying with Vanna AI & LLaMA 3

This project demonstrates how to use Vanna AI, a framework that combines LLMs like ChatGPT and LLaMA, to translate natural language into SQL queries, enabling intuitive interaction with databases.

## 📌 Features
- Combine LLMs with SQL databases for seamless querying
- Support for ChatGPT and LLaMA 3 as backend models
- Integration with Chroma DB for vector storage
- Custom class implementation for enhanced query handling
- Live demo using Chinook MySQL database
